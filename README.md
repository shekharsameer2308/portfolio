## 🏛️ Positioning & Core Narrative

This is not a generic tutorial developer portfolio. It is engineered to communicate a sharp, distinct identity:

$$\text{Chemical Engineering} \longrightarrow \text{Industrial Data} \longrightarrow \text{Machine Learning} \longrightarrow \text{AI Systems} \longrightarrow \text{Production Engineering}$$

### Key Differentiators
- **Physical Grounding**: Experience with real industrial datasets, proximate coal assays (CCL), and material characterization (Tata Steel R&D).
- **Systems Thinking**: Moving beyond isolated models to building entire architectures around them (Kafka streaming, DuckDB query engines, PostgreSQL star schemas, Prometheus observability).
- **Verified Capabilities**: Zero fabricated claims, direct source links to verified repositories, and transparent technical case studies.

---

## 🚀 Featured Engineering Systems

1. **[Analyzer](https://analyzer-self.vercel.app/)** *(Flagship)*: Coal quality analytics, Gross Calorific Value (GCV) non-linear XGBoost prediction, multivariate anomaly detection, and linear programming blending optimization.
2. **NEXUS**: Real-time e-commerce event streaming data platform with Apache Kafka, PostgreSQL star schema data warehousing, Prophet forecasting, and WebSocket telemetry broadcasting.
3. **Scout**: Financial NLP and market intelligence RAG platform utilizing FinBERT sentiment analysis, BERTopic clustering, and Qdrant vector search retrieval with grounded citations.
4. **[TrackFin](https://track-fin-bay.vercel.app/)**: Proactive behavioral personal finance SaaS featuring smart categorization heuristics, burn rate calculations, and guest sandbox provisioning.
5. **ParkWay**: Multi-agent validation workflow system for healthcare provider directory extraction, OCR parsing, and registry cross-verification.
6. **ML Models & Mathematical Foundations**: Scratch NumPy vector implementations and benchmark comparisons of core regression, classification, clustering, and optimization algorithms.

## 💻 Tech Stack & Architecture

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Static Prerendering)
- **Language**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Styling & Tokens**: [Tailwind CSS](https://tailwindcss.com/) with dark-mode first design tokens
- **Icons**: Custom SVG + [Lucide Icons](https://lucide.dev/)
- **Animation & Visuals**: Lightweight CSS keyframes + Framer Motion
- **Deployment**: Vercel Edge Network / Static Export
- **CI/CD**: GitHub Actions

## 🛠️ Local Development

### Prerequisites
- Node.js >= 18.17.0
- npm >= 9.0.0

### Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/shekharsameer2308/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

### Production Build

```bash
# Verify static build and TypeScript types
npm run build

# Preview production build locally
npm run start
```
